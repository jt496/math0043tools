# Visualisations and Tools for MATH0043 (Group Theory and Calculus of Variations)

A collection of interactive web-based visualisations for exploring group theory, built for the [MATH0043 Mathematics for Physics and Astronomy](https://www.ucl.ac.uk/module-catalogue/modules/MATH0043) module at [UCL](https://www.ucl.ac.uk/) with lots of help from Claude and Gemini.

**🌐 Live site: [jt496.github.io/groups](https://jt496.github.io/math0043tools/)**

## Overview

These visualisations let you explore examples, computations and concepts from group theory and CoV with animated 3D models and computational tools. Everything runs in the browser — no installation required.

Built with HTML, CSS, and JavaScript. 3D visualisations use [Three.js](https://threejs.org/). No build step — the site is a collection of static pages.

## Running Locally

Serve the `math0043tools/` directory with any static file server:

```bash
cd math0043tools
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).
