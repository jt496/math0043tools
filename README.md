# Visualisations and Tools for MATH0043 (Group Theory and Calculus of Variations)

A collection of interactive web-based visualisations for exploring group theory and the calculus of variations, built for the [MATH0043 Mathematics for Physics and Astronomy](https://www.ucl.ac.uk/module-catalogue/modules/MATH0043) module at [UCL](https://www.ucl.ac.uk/) with lots of help from Claude and Gemini.

**🌐 Live site: [jt496.github.io/math0043tools](https://jt496.github.io/math0043tools/)**

## Overview

These visualisations let you explore examples, computations and concepts from group theory and the calculus of variations through animated 3D models, Cayley graphs and other interactive tools. Everything runs in the browser — no installation required.

## Structure

### ∫ Calculus of Variations (`CoV/`)
- **Lecture slides** — the theory, history and applications of the calculus of variations
- **Euler–Lagrange equation** — perturb a candidate by εη and watch I(ε): why an extremal is a
  stationary point, why a wrong candidate is not, and why one variation is never enough
- **Lagrange multipliers** — constrained optimisation in 3D, and the geometry behind ∇f = λ∇g
- **Brachistochrone** — the path of quickest descent under gravity, and its cycloid solution
- **Soap bubbles** — catenoids and the minimal surface problem between two rings, including the stable, unstable and Goldschmidt solutions
- **Dido's problem** — the curve bounding maximum area for a given perimeter

### ⬡ Plane Symmetries (`groups/plane/`)
- **Cyclic groups** — rotational symmetries Cₙ
- **Dihedral groups** — symmetries of regular polygons Dₙ
- **Rectangle symmetries** — the Klein four-group V₄
- **Frieze groups** — the 7 symmetry groups of frieze patterns
- **Wallpaper groups** — the 17 symmetry groups of the plane
- **Triangle groups** — groups generated by reflections

### ▲ Symmetries of Polyhedra (`groups/polyhedra/`)
- **Tetrahedron** — rotational (A₄) and full symmetry group (S₄)
- **Cube** — rotational (S₄) and full symmetry group (S₄ × C₂)
- **Dodecahedron** — rotational (A₅) and full symmetry group (A₅ × C₂)

### ⤨ Permutations & Integers mod n (`groups/algebra/`)
- **Permutations in Sₙ** — compose permutations, explore cycle notation
- **Addition mod n** — the additive group ℤ/nℤ
- **Units mod n** — the multiplicative group (ℤ/nℤ)×

### ⧉ Lagrange & Subgroups (`groups/structure/`)
- **Cosets & Lagrange's Theorem** — visualise coset partitions
- **Subgroup lattices** — Hasse diagrams of subgroup inclusion

### 🛠 Tools (`groups/structure/`)
- **Cayley graphs** — interactive graph explorer for any finite group
- **Group presentations** — generators and relations
- **Homomorphisms** — visualise group homomorphisms
- **Representations** — matrix representations of groups

### ✦ Other Topics (`groups/other/`)
- **Rubik's Cube** — the Rubik's Cube group

## Technology

Built with HTML, CSS, and JavaScript. 3D visualisations use [Three.js](https://threejs.org/). No build step — the site is a collection of static pages, deployed to GitHub Pages from the repository root.

## Running Locally

Serve the repository root with any static file server:

```bash
git clone https://github.com/jt496/math0043tools.git
cd math0043tools
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000) for the landing page linking to both sections.
