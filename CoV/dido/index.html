Dido's Problem

\[ \frac{\theta}{\sin(\theta)} = c \]

This equation arises in Dido's Problem, which seeks the curve of fixed length \(\ell\) between two points that encloses the maximum area. The optimal curve is a circular arc.

Let the two points be separated by a distance \(2a\). If the circular arc has radius \(R\) and subtends an angle \(2\theta\) at its center, its arc length is \(\ell = 2R\theta\) and the chord length is \(2a = 2R\sin(\theta)\). Taking the ratio gives \(\frac{\ell}{2a} = \frac{\theta}{\sin(\theta)} = c\).

Mathematical Properties

  • The function \(f(\theta) = \frac{\theta}{\sin(\theta)}\) is even: \(f(-\theta) = f(\theta)\).
  • We have \(\lim_{\theta \to 0} \frac{\theta}{\sin(\theta)} = 1\), corresponding to a straight line (\(\ell = 2a\)).
  • Vertical asymptotes occur at all \(\theta = n\pi\) for non-zero integers \(n\).
  • In each interval \((n\pi, (n+1)\pi)\), there is exactly one local extremum point at the non-zero root of \(\tan(\theta) = \theta\).

Physical Interpretation

For Dido's problem, only the principal root \(\theta \in (0, \pi)\) is geometrically meaningful for a simple non-self-intersecting arc bounding an area against a straight line.
