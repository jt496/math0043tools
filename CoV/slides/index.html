What is a Functional?

Definition

A functional is a rule that assigns a number to each function :

\[ J: \mathcal{F} \to \mathbb{R} \]

where \(\mathcal{F}\) is some space of functions.

Input: a function \(y(x)\)   → Output: a single number

The Euler-Lagrange Equation

The Standard Problem

We focus on functionals of the form:

\[ I[y] = \int_a^b F(x, y, y') \, dx \]

with boundary conditions : \(y(a) = A\), \(y(b) = B\)

\(y = y(x)\) — the unknown function we seek

\(y' = dy/dx\) — its derivative

\(F(x, y, y')\) — a given function of three variables

The Euler-Lagrange Equation

The Euler-Lagrange Equation

Theorem (Euler-Lagrange Equation)

If \(y(x)\) is an extremal of \(I[y] = \int_a^b F(x, y, y') \, dx\), then:

\[ \boxed{\frac{\partial F}{\partial y} - \frac{d}{dx}\left(\frac{\partial F}{\partial y'}\right) = 0} \]

Often written as: \(F_y - \frac{d}{dx}{F_{y'}} = 0\)

The Euler-Lagrange Equation

Candidate Extremals

Definition

A function \(y(x)\) is a candidate extremal if it satisfies the Euler-Lagrange equation.

Ordinary Calculus Calculus of Variations
Critical point: \(f'(x^*)=0\) Candidate: E-L satisfied
Could be max, min, saddle Could be max, min, neither

⚠️ Warning

A candidate extremal is not necessarily a minimum or maximum—it's a stationary point of the functional.

Fundamental Lemma of CoV

Fundamental Lemma of CoV

If \(M(x)\) is continuous on \([a,b]\) and

\[ \int_a^b M(x) \eta(x) \, dx = 0 \]

for all smooth \(\eta\) with \(\eta(a) = \eta(b) = 0\), then:

\[ M(x) = 0 \quad \text{for all } x \in [a,b] \]
The Euler-Lagrange Equation

Derivation Sketch

Let \(y(x)\) be an extremal of \(I[y] = \int_a^b F(x, y, y') \, dx\).

Let \(\eta\) be a smooth test function satisfying \(\eta(a) = \eta(b) = 0\).

For \(\epsilon\) small, let \(y_\epsilon (x) = y +\epsilon \eta \), then \[y'_\epsilon = y' + \epsilon \eta',\qquad \frac{d y_\epsilon}{d \epsilon} = \eta \qquad \frac{d y'_\epsilon}{d \epsilon} = \eta'.\]

Since \(y\) is an extremal of the functional \(I\): \[\frac{d}{d\epsilon}I[y + \epsilon\eta]\Big|_{\epsilon=0} = 0.\]
Differentiating under the integral using chain rule:
\[\frac{d}{d\epsilon}I[y + \epsilon\eta] = \int_a^b \frac{d}{d\epsilon} F(x, y_\epsilon, y'_\epsilon) \, dx=\int_a^b \left[ \frac{\partial F}{\partial y_{\epsilon}} \eta + \frac{\partial F}{\partial y_{\epsilon}'} \eta' \right] dx.\]
Setting \(\epsilon = 0\) we obtain:
\[\int_a^b \frac{\partial F}{\partial y} \eta + \frac{\partial F}{\partial y'} \eta'\, dx = 0.\]
Integration by parts and the boundary conditions on \(\eta\) give:
\[\int_a^b \frac{\partial F}{\partial y'} \eta' dx = \underbrace{\left[\frac{\partial F}{\partial y'} \eta\right]_a^b}_{=\,0} - \int_a^b \left(\frac{d}{dx}\frac{\partial F}{\partial y'}\right) \eta \, dx\]
Hence:
\[\qquad\int_a^b \left( \frac{\partial F}{\partial y} - \frac{d}{dx}\frac{\partial F}{\partial y'} \right) \eta \, dx = 0\]
Since this holds for all test functions \(\eta\) the Fundamental Lemma of the Calculus of Variations gives:
\[\frac{\partial F}{\partial y} - \frac{d}{dx}\frac{\partial F}{\partial y'} = 0.\]
The Euler-Lagrange Equation

Special Case: First Integral

First Integral

If \(\frac{\partial F}{\partial y} = 0\), then the E-L equation becomes:

\[ \frac{d}{dx}\left(\frac{\partial F}{\partial y'}\right) = 0 \]

This integrates immediately to give:

\[ \boxed{\frac{\partial F}{\partial y'} = C} \]

where \(C\) is a constant of integration.

Deriving the Arc Length Functional

Consider a curve \(y = y(x)\) from \((a, A)\) to \((b, B)\).

Displacement: \(d\mathbf{r} = dx\,\mathbf{i} + dy\,\mathbf{j}\)
\(ds = |d\mathbf{r}| = \sqrt{dx^2 + dy^2}\)
Factor out \(dx\): \(ds = \sqrt{1 + (y')^2}\, dx\)
\[ I[y] = \int_a^b \sqrt{1 + (y')^2}\, dx \]

\(F = \sqrt{1 + (y')^2}\) doesn't depend on \(y\)!

The Euler-Lagrange Equation

Shortest Path in the Plane

Problem: Minimize arc length from \((0,0)\) to \((1,1)\)

\[ I[y] = \int_0^1 \sqrt{1 + (y')^2} \, dx \]
\[\frac{\partial F}{\partial y} = 0,\qquad \frac{\partial F}{\partial y'} = \frac{y'}{\sqrt{1+(y')^2}}.\]
Since \(\frac{\partial F}{\partial y}=0\) we have a First Integral in the EL-equation!
\[ \Rightarrow \frac{y'}{\sqrt{1+(y')^2}} = C \]
\[ \Rightarrow y' = \text{const} \Rightarrow y = mx + c \]
BCs yield the solution: \(y(x) = x\).

Deriving Path Length on a Cylinder

Cylindrical coords: \((r, \theta, z)\) with \(r = 1\).

\(\mathbf{r} = (\cos\theta, \sin\theta, z)\)
\(ds^2 = dx^2 + dy^2 + dz^2\)
\(dx = -\sin\theta \, d\theta, \qquad dy = \cos\theta \, d\theta\)
\(ds= \sqrt{d\theta^2 + dz^2}= \sqrt{(\theta')^2 + 1}\, dz.\)
\[ I[\theta] = \int_{z_1}^{z_2} \sqrt{(\theta')^2 + 1}\, dz \]

\(F\) doesn't depend on \(\theta\) — First Integral!

The Euler-Lagrange Equation

Geodesics on a Cylinder

Pitch:

Find the shortest path on a cylinder of radius 1.

\[ I[\theta] = \int_{z_1}^{z_2} \sqrt{(\theta')^2 + 1} \, dz \]
Since \(\frac{\partial F}{\partial \theta}=0\) we have a First Integral!
\[\frac{\theta'}{\sqrt{(\theta')^2 + 1}} = C\quad \Rightarrow \quad \theta = az + b.\]
A helix! (straight line when unwrapped)

Deriving Path Length on a Sphere

Spherical coords: \((r, \theta, \phi)\) with \(r = 1\). So \(\theta\) is the angle down from the z-axis, and \(\phi\) is the azimuthal angle in the xy-plane.

\(\mathbf{r} = (\sin\theta\cos\phi, \sin\theta\sin\phi, \cos\theta)\)
\(ds^2 = dx^2 + dy^2 + dz^2\)
\(dx = \cos\theta\cos\phi \, d\theta - \sin\theta\sin\phi \, d\phi\)
\(dy = \cos\theta\sin\phi \, d\theta + \sin\theta\cos\phi \, d\phi\)
\(dz = -\sin\theta \, d\theta\)
\(ds = \sqrt{1 + \sin^2\theta\, (\phi')^2}\, d\theta\).
The Euler-Lagrange Equation

Example: Geodesic on a Sphere

Find the shortest path on a sphere of radius 1.

\[ I[\phi] = \int_{\theta_1}^{\theta_2} \sqrt{1 + \sin^2\theta (\phi')^2} \, d\theta \]
\(\frac{\partial F}{\partial \phi} = 0\), so \(\frac{\partial F}{\partial \phi'} = \frac{\phi'\sin^2\theta }{\sqrt{1 + \sin^2\theta (\phi')^2}}\)
Since \(\frac{\partial F}{\partial \phi}=0\) we have a First Integral!
\[\frac{\phi' \sin^2\theta }{\sqrt{1 + \sin^2\theta (\phi')^2}} = C.\]
Solution: Planes through the origin (Great Circles)
Applications

Deriving Kepler's Second Law

Kepler's Second Law

A line joining a planet and the Sun sweeps out equal areas in equal times.

Hamilton's Principle of Least Action

The path a physical system takes between two fixed points in time extremizes the action:

\[ S = \int_{t_1}^{t_2} L\,dt \]

where \(L\) is the Lagrangian of the system.

For a particle of mass \(m\) under central potential \(V(r)\) use the Lagrangian in polar coordinates:

\[ L = \tfrac12 m\big(\dot r^2 + r^2\dot\theta^2\big) - V(r). \]

Note that \(L\) has no explicit \(\theta\)-dependence!

There are two Euler–Lagrange equations (one for each generalized coordinate):

\[ \frac{d}{dt}\frac{\partial L}{\partial \dot r} - \frac{\partial L}{\partial r} = 0, \]
\[ \frac{d}{dt}\frac{\partial L}{\partial \dot\theta} - \frac{\partial L}{\partial \theta} = 0. \]

The angular equation is a First Integral since \(\partial L/\partial \theta = 0\):

\[ \frac{d}{dt}\big(m r^2\dot\theta\big) = 0 \quad\Rightarrow\quad m r^2\dot\theta = h.\]

The lack of \(\theta\)-dependence in \(L\) corresponds to a rotational symmetry of the system, which implies conservation of angular momentum. (This is Noether's theorem in action!)

Applications

Kepler's Second Law

Angular momentum is conserved: \[ mr^2\dot{\theta} = h \quad\text{(constant)}\]

Area swept: \[ dA = \frac{1}{2}r(r d\theta)= \frac{1}{2}r^2 d\theta\]
\[\frac{dA}{dt} = \frac{dA}{d\theta}\dot{\theta} = \frac{1}{2}r^2\dot{\theta} = \frac{h}{2m}\]

The Two-Body Problem

Two masses \(m_1, m_2\) interacting via gravity.

Lagrangian in inertial frame:

\[ L = \frac{1}{2}m_1\dot{\mathbf{r}}_1^2 + \frac{1}{2}m_2\dot{\mathbf{r}}_2^2 - V(|\mathbf{r}_1 - \mathbf{r}_2|) \]

Reduce to relative coordinate \(\mathbf{r} = \mathbf{r}_1 - \mathbf{r}_2\):

\[ L = \frac{1}{2}\mu\dot{\mathbf{r}}^2 - V(r), \quad \mu = \frac{m_1 m_2}{m_1 + m_2} \]
Equivalent to a single particle of mass \(\mu\) in a central potential!

The Beltrami Identity

The Beltrami Identity

A powerful shortcut when \(F\) doesn't depend on \(x\)

Beltrami Applies ✓

  • \(F = \sqrt{1 + (y')^2}\)
  • \(F = y\sqrt{1 + (y')^2}\)
  • \(F = (y')^2 + y^2\)

No explicit \(x\) dependence

Beltrami Does NOT Apply ✗

  • \(F = x(y')^2\)
  • \(F = xy + (y')^2\)
  • \(F = e^x\sqrt{1 + (y')^2}\)

Contains explicit \(x\)

The Beltrami Identity

Beltrami Identity

Theorem

If \(F = F(y, y')\) (no explicit \(x\)), then any candidate extremal satisfies:

\[ \boxed{F - y' \frac{\partial F}{\partial y'} = C} \]

where \(C\) is a constant.

💡

Euler-Lagrange: 2nd order ODE

Beltrami: 1st order ODE — usually easier!

Isoperimetric Problems

Isoperimetric Problems

Optimization with constraints

Find \(y(x)\) that extremizes:

\[ I[y] = \int_a^b F(x, y, y') \, dx \]

subject to the constraint :

\[ K[y] = \int_a^b G(x, y, y') \, dx = \ell \quad \text{(fixed)} \]

Classic example: Of all curves with perimeter \(L\), which encloses maximum area?

Isoperimetric Problems

Lagrange Multipliers for Functionals

Method

Form the augmented functional :

\[ \tilde{J}[y] = \int_a^b \left[ F + \lambda G \right] dx \]

Solve E-L for \(H = F + \lambda G\), then use constraint to find \(\lambda\).

Result: Maximum area with fixed perimeter → Circle!
